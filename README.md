# London House Price Analysis (Tableau)

This project analyzes London housing prices using a public Kaggle dataset and builds a Tableau dashboard to explore:
- Price trends over time
- Price differences by property type / tenure
- Energy rating vs price
- Bedrooms/Bathrooms vs price
- Geographic patterns by postcode

## Files
- `Final Project.twb` — Tableau workbook (dashboard)
- `CIS 240 Final Project.pptx` — project presentation (methods + findings)
- `screenshots/` — exported dashboard images (recommended for quick viewing)

## How to view
1. Quick view: open images in `screenshots/`
2. Full interactive dashboard: open `Final Project.twb` in Tableau

## Data
Raw data is not included in this repo (file size). Source: Kaggle (London house price dataset).
